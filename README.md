# Todd Test Tracker

An independent personal task tracker based on the BSSC tracker’s visual layout and workflow.

- Five color-coded tiers
- Ready, Working, Waiting, and Done statuses
- Reminder cadence and activity log
- Starts with no tasks
- Stores its data separately in this browser under `TODD_TEST_*` keys

## Publish it on your personal GitHub

1. Create an empty repository named `todd-test-tracker` on your personal GitHub account. Do not add a README during setup.
2. Upload the included `index.html` file to that repository.
3. In the repository, open **Settings → Pages**, choose **Deploy from a branch**, then choose **main** and **/(root)**. Save.

GitHub will give you the website link in a minute or two.
